## 📝 Что изменилось:

### Формы:
- **Регистрация:** Поле "Email адрес" вместо "Номер телефона"
- **Вход:** Поле "Email адрес" вместо "Номер телефона"

### База данных:
```javascript
// Старая структура User:
{
  user_phone: "79001234567",
  user_password: "123456"
}

// Новая структура User:
{
  user_email: "ivan@mail.com"
  // пароль только в Firebase Auth
}
```

---

## 🚀 Что нужно сделать:

### 1. Убедитесь что Email/Password включен
Firebase Console → Authentication → Sign-in method → Email/Password → Enable

### 2. Очистите старые данные (если есть)
Если у вас уже были пользователи с телефонами:
- Firebase Console → Firestore → users → Удалите старые документы

### 3. Перезапустите приложение
```bash
npm run dev
```

### 4. Протестируйте
- Откройте http://localhost:3001
- Регистрация → Введите email
- Заполните профиль
- Готово!
