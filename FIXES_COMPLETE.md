### MainScreen.tsx:
```typescript
// БЫЛО:
useEffect(() => {
  if (questions.length > 0 && !hasCompletedTest) {
    setShowTestNotification(true);
  }
}, [questions, hasCompletedTest]);

// СТАЛО:
useEffect(() => {
  // Показываем тест только если не прошел и тест еще не был показан
  if (questions.length > 0 && !hasCompletedTest && !showTestNotification) {
    setShowTestNotification(true);
  }
  // Скрываем тест, если пользователь прошел его
  if (hasCompletedTest && showTestNotification) {
    setShowTestNotification(false);
  }
}, [questions.length, hasCompletedTest]);
```

## 🔄 Логика мэтчинга:

```
User A лайкает User B
    ↓
Запись в likes: {from: A, to: B}
    ↓
User B лайкает User A
    ↓
Запись в likes: {from: B, to: A}
    ↓
checkForMutualLikes() находит взаимный лайк
    ↓
Создается match: {user1: A, user2: B}
    ↓
✅ MATCH! Оба видят друг друга в "Матчах"
```
