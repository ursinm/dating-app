# 🔄 Почему выкидывает в авторизацию?

## ✅ ЭТО НОРМАЛЬНО! Вот почему:

После миграции на **email** старые пользователи с `user_phone` больше не существуют в базе данных.

---

## 🔍 Что происходит:

### Шаг 1: Вы открываете профиль
```
ProfileScreen загружается
    ↓
Читает userId из localStorage (старый ID)
    ↓
Запрашивает usersApi.getById(userId)
```

### Шаг 2: Пользователь не найден
```
База данных: "Пользователя с таким ID нет"
    ↓
userData = null
```

### Шаг 3: Автоматическая очистка
```
if (!userData) {
  authManager.logout()      // Очищаем localStorage
  navigate('/welcome')      // Перенаправляем
}
```

### ✅ Результат: Вы на странице авторизации

---

## 💡 ЭТО ПРАВИЛЬНО! Потому что:

1. **Старые данные невалидны**
   - В localStorage userId от старого пользователя
   - Тот пользователь имел `user_phone`
   - После миграции пользователи с `user_phone` удалены
   - Нужны новые пользователи с `user_email`

2. **Безопасность**
   - Если пользователь не найден → сессия невалидна
   - Правильно выполнить logout и запросить повторный вход

3. **Чистота данных**
   - Старые данные очищаются автоматически
   - Не нужно вручную чистить localStorage

### Вариант 2: Создать тестовых пользователей в Firestore

#### Через Firebase Console:
1. Откройте Firebase Console → Firestore
2. Коллекция `users` → **Add document**
3. Создайте документ:
```javascript
{
  user_id: 1,
  user_name: "Тест",
  user_email: "test@mail.com",
  user_age: 25,
  user_gender: "male",
  user_description: "Тестовый пользователь",
  user_photo_url: null,
  created_at: timestamp,
  updated_at: timestamp
}
```

4. Firebase Console → Authentication → Users → Add User:
```
Email: test@mail.com
Password: 123456
```

5. Войдите с этими данными
6. ✅ Профиль работает!
