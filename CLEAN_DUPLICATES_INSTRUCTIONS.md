# 🧹 ИНСТРУКЦИЯ ПО ОЧИСТКЕ ДУБЛЕЙ

## ❌ Проблема:

В базе данных есть дублирующиеся вопросы и варианты ответов:
- Показывается "Вопрос 1 из 20" вместо "из 10"
- Варианты ответов дублируются (например "Дома, в уютной обстановке" появляется дважды)

## ✅ Решение:

### Вариант 1: Через консоль браузера (РЕКОМЕНДУЕТСЯ)

1. **Откройте приложение** в браузере
2. **Нажмите F12** (открыть DevTools)
3. **Перейдите на вкладку Console**
4. **Вставьте и выполните** этот код:

```javascript
// Импортируем функции очистки
import('./src/lib/cleanDuplicates.js').then(module => {
  // Сначала покажем статистику
  module.showDuplicatesStats().then(() => {
    // Спросим подтверждение
    if (confirm('Очистить дубли? Это удалит лишние записи.')) {
      // Запускаем очистку
      module.cleanAllDuplicates().then(() => {
        alert('✅ Дубли успешно удалены! Обновите страницу.');
        location.reload();
      });
    }
  });
});
```

### Вариант 2: Через код приложения

Добавьте кнопку в ProfileScreen.tsx:

```typescript
import { cleanAllDuplicates, showDuplicatesStats } from '../lib/cleanDuplicates';

// В компоненте:
const handleCleanDuplicates = async () => {
  await showDuplicatesStats();
  if (window.confirm('Очистить дубли?')) {
    await cleanAllDuplicates();
    alert('Готово! Обновите страницу.');
  }
};

// В JSX:
<button onClick={handleCleanDuplicates}>
  🧹 Очистить дубли
</button>
```

### Вариант 3: Удалить всю коллекцию и пересоздать

1. **Откройте Firebase Console:**
   ```
   https://console.firebase.google.com/project/dating-main-14a43/firestore
   ```

2. **Удалите коллекции:**
   - Перейдите в `questions` → Удалите все документы
   - Перейдите в `answer_opinions` → Удалите все документы
   - Перейдите в `user_answers` → Удалите все документы

3. **Обновите приложение:**
   - Откройте приложение
   - Данные пересоздадутся автоматически (БЕЗ ДУБЛЕЙ!)
