## 🚀 Следующий шаг:

### Обновите план Firebase до Blaze:

1. Перейдите по ссылке:
   https://console.firebase.google.com/project/dating-main-14a43/usage/details

2. Нажмите **"Upgrade to Blaze"**

3. Подтвердите обновление

4. Разверните функции:
   ```bash
   cd mobile
   firebase deploy --only functions
   ```

## 📋 Что происходит после развертывания:

### Автоматические уведомления:

1. **При новом сообщении:**
   - Функция `sendMessageNotification` автоматически срабатывает
   - Получатель получает push-уведомление с именем отправителя и текстом сообщения
   - Уведомление содержит данные для открытия чата

2. **При новом матче:**
   - Функция `sendMatchNotification` автоматически срабатывает
   - Оба пользователя получают уведомление о новом матче
   - Уведомление содержит данные для перехода к экрану матчей

## 🔍 Проверка работы:

После развертывания проверьте:

1. **В Firebase Console:**
   - Functions → должны быть видны две функции
   - Functions → Logs → можно просматривать логи

2. **В приложении:**
   - Войдите под двумя разными пользователями
   - Отправьте сообщение от одного другому
   - Второй должен получить push-уведомление

## 🆘 Решение проблем:

1. **Уведомления не приходят:**
   - Проверьте, что FCM токен сохранен в Firestore (поле `fcm_token` в коллекции `users`)
   - Проверьте логи функций на наличие ошибок
   - Убедитесь, что разрешения на уведомления предоставлены

2. **Функции не развертываются:**
   - Убедитесь, что план обновлен до Blaze
   - Проверьте, что вы авторизованы: `firebase login`
   - Проверьте права доступа к проекту

3. **Ошибки в логах:**
   - Проверьте структуру данных в Firestore (должны соответствовать моделям)
   - Убедитесь, что поля `user_id`, `chat_id`, `match_id` имеют правильные типы
