# Инструкция по развертыванию Cloud Functions

## ⚠️ Важное требование

Для развертывания Cloud Functions проект Firebase должен быть на **плане Blaze (pay-as-you-go)**.

## Шаги для развертывания:

### 1. Обновление плана Firebase

1. Перейдите по ссылке: https://console.firebase.google.com/project/dating-main-14a43/usage/details
2. Нажмите **"Upgrade to Blaze"** (Обновить до Blaze)
3. Подтвердите обновление

**Примечание:** План Blaze имеет бесплатный лимит:
- 2 миллиона вызовов функций в месяц
- 400,000 GB-секунд вычислительного времени
- 200,000 HTTP запросов в месяц

Для небольшого приложения это более чем достаточно.

### 2. Развертывание функций

После обновления плана выполните:

```bash
cd mobile
firebase deploy --only functions
```

### 3. Проверка развертывания

После успешного развертывания вы увидите URL функций:

```
✔  functions[sendMessageNotification(us-central1)] 
   Successful create operation.
✔  functions[sendMatchNotification(us-central1)] 
   Successful create operation.
```

### 4. Проверка работы

1. Откройте Firebase Console → Functions
2. Вы должны увидеть две функции:
   - `sendMessageNotification`
   - `sendMatchNotification`

### 5. Тестирование уведомлений

#### Тест уведомления о сообщении:
1. Откройте приложение на двух разных устройствах/эмуляторах
2. Войдите под разными пользователями
3. Создайте матч между ними
4. Отправьте сообщение от одного пользователя другому
5. Второй пользователь должен получить push-уведомление

#### Тест уведомления о матче:
1. Откройте приложение на двух разных устройствах
2. Войдите под разными пользователями
3. Один пользователь должен поставить лайк другому
4. Когда второй пользователь также поставит лайк, оба должны получить уведомление о новом матче

## Альтернативный вариант (без Cloud Functions)

Если вы не хотите обновлять план Firebase, можете использовать Firebase Cloud Messaging напрямую из вашего приложения или настроить отдельный сервер.

Но для production рекомендуется использовать Cloud Functions, так как они:
- Автоматически масштабируются
- Надежны и безопасны
- Легко настраиваются
- Имеют бесплатный лимит, достаточный для большинства приложений

## Логи и отладка

После развертывания вы можете смотреть логи функций:

```bash
firebase functions:log
```

Или в Firebase Console:
1. Откройте Functions → Logs
2. Выберите нужную функцию
3. Просматривайте логи в реальном времени

## Поддержка

Если возникли проблемы:
1. Проверьте, что план обновлен до Blaze
2. Убедитесь, что Firebase CLI установлен и вы авторизованы
3. Проверьте логи функций на наличие ошибок
4. Убедитесь, что FCM токены сохраняются для пользователей
