## 🐛 Исправление времени last_seen:

### Проблема:
```
Показывало: "был давно"
Причина: last_seen приходил как undefined или невалидная дата
```

### Решение:
```typescript
export function formatLastSeen(lastSeen: string | undefined): string {
  // 1. Проверка на undefined
  if (!lastSeen) {
    console.log('⚠️ last_seen отсутствует');
    return 'давно';
  }
  
  try {
    const lastSeenDate = new Date(lastSeen);
    
    // 2. Проверка валидности даты
    if (isNaN(lastSeenDate.getTime())) {
      console.error('❌ Невалидная дата last_seen:', lastSeen);
      return 'давно';
    }
    
    const diffMs = now.getTime() - lastSeenDate.getTime();
    
    // 3. Проверка на время в будущем
    if (diffMs < 0) {
      return 'только что';
    }
    
    // 4. Форматирование
    if (diffMins < 1) return 'только что';
    if (diffMins < 60) return `${diffMins} мин назад`;
    // ...
  } catch (error) {
    console.error('❌ Ошибка форматирования last_seen:', error);
    return 'давно';
  }
}
```

### Отладка:
```
Откройте Console (F12) и проверьте логи:
✅ "⚠️ last_seen отсутствует" - поле не установлено
✅ "❌ Невалидная дата" - некорректный формат
```
