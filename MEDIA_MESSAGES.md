# 📷🎤 МЕДИА-СООБЩЕНИЯ: ФОТО И ГОЛОСОВЫЕ

## 🎉 Новый функционал:

### 1. **Отправка фотографий** 📷
- Нажмите кнопку **скрепки** (📎) слева от поля ввода
- Выберите изображение (макс 5MB)
- Появится превью
- Нажмите "Отправить фото"
- ✅ Фото загружается в Firebase Storage и отправляется

### 2. **Голосовые сообщения** 🎤
- Когда поле ввода пустое, справа появляется кнопка **микрофона**
- Нажмите чтобы начать запись
- Индикатор показывает длительность записи
- Нажмите "Отправить" чтобы отправить
- Или "X" чтобы отменить
- ✅ Голосовое сохраняется в Firebase Storage и отправляется

### 3. **Отображение медиа** 🖼️
- **Фото**: показываются в полном размере (макс 96px высота)
- **Голосовые**: встроенный аудио-плеер с длительностью

## 🎯 Как пользоваться:

### Отправить фото:
```
1. Откройте чат
2. Нажмите [📎] скрепку
3. Выберите изображение
4. Увидите превью
5. Нажмите "Отправить фото"
6. ✅ Фото отправлено!
```

### Отправить голосовое:
```
1. Откройте чат
2. Оставьте поле ввода пустым
3. Нажмите [🎤] микрофон
4. Разрешите доступ к микрофону (если нужно)
5. Говорите (идёт запись)
6. Нажмите "Отправить"
7. ✅ Голосовое отправлено!
```

### Отменить запись голосового:
```
1. Во время записи
2. Нажмите [X]
3. ✅ Запись отменена
```

## ⚡ Особенности:

### 1. Firebase Storage
- Все файлы хранятся в Firebase Storage
- URL генерируется автоматически
- Доступ к файлам защищён правилами Security Rules

### 2. Валидация фото
- Проверка типа файла (только изображения)
- Проверка размера (макс 5MB)
- Превью перед отправкой

### 3. MediaRecorder API
- Запись в формате WebM
- Работает в современных браузерах
- Требует разрешения доступа к микрофону

### 4. Умная кнопка
- Есть текст → кнопка отправки (📤)
- Нет текста → кнопка микрофона (🎤)

### 5. Превью и индикаторы
- Превью фото перед отправкой
- Индикатор записи голосового
- Таймер длительности записи
