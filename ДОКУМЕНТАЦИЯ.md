## 📱 О проекте

**Dating App** - современное веб-приложение для знакомств с уникальной системой подбора партнеров на основе совместимости.

### Ключевые особенности:
- ✅ Тест на совместимость (10 вопросов)
- ✅ Умный подбор на основе общих ценностей
- ✅ Система лайков и мэтчей
- ✅ Чаты в реальном времени
- ✅ Загрузка фото профиля
- ✅ Восстановление пароля
- ✅ Адаптивный дизайн

### Для кого:
- Люди, ищущие серьезные отношения
- Те, кто ценит совместимость характеров
- Пользователи, которым важны общие ценности

## 🗄 База данных

### Структура БД (Firebase Firestore):

#### Коллекция: users (Пользователи)
```javascript
- user_id (number) - ID пользователя
- user_name (string) - Имя
- user_phone (string) - Номер телефона (уникальный)
- user_password (string) - Пароль
- user_age (number) - Возраст
- user_gender (string) - Пол
- user_description (string) - Описание профиля
- user_photo_url (string) - URL аватарки (base64 или ссылка)
- created_at (timestamp) - Дата создания
- updated_at (timestamp) - Дата обновления
```

#### Коллекция: questions (Вопросы теста)
```javascript
- question_id (number) - ID вопроса
- question_text (string) - Текст вопроса
- question_order (number) - Порядок отображения
- created_at (timestamp) - Дата создания
```

#### Коллекция: answer_opinions (Варианты ответов)
```javascript
- opinion_id (number) - ID варианта
- question_id (number) - ID вопроса
- opinion_text (string) - Текст варианта
- opinion_value (number) - Значение для расчета совместимости
- created_at (timestamp) - Дата создания
```

#### Коллекция: user_answers (Ответы пользователей)
```javascript
- answer_id (number) - ID ответа
- user_id (number) - ID пользователя
- question_id (number) - ID вопроса
- opinion_id (number) - ID выбранного варианта
- created_at (timestamp) - Дата ответа
```

#### Коллекция: likes (Лайки)
```javascript
- like_id (number) - ID лайка
- from_user_id (number) - Кто поставил лайк
- to_user_id (number) - Кому поставлен лайк
- created_at (timestamp) - Дата лайка
```

#### Коллекция: matches (Мэтчи)
```javascript
- match_id (number) - ID мэтча
- match_first_user_id (number) - Первый пользователь
- match_second_user_id (number) - Второй пользователь
- created_at (timestamp) - Дата создания мэтча
```

#### Коллекция: chats (Чаты)
```javascript
- chat_id (number) - ID чата
- chat_first_user_id (number) - Первый пользователь
- chat_second_user_id (number) - Второй пользователь
- created_at (timestamp) - Дата создания чата
```

#### Коллекция: messages (Сообщения)
```javascript
- message_id (number) - ID сообщения
- chat_id (number) - ID чата
- sender_id (number) - ID отправителя
- message_text (string) - Текст сообщения
- created_at (timestamp) - Дата отправки
```

### Настройка БД:

1. Создайте проект в [Firebase Console](https://console.firebase.google.com/)
2. Включите Firestore Database
3. Скопируйте конфигурацию проекта
4. Обновите `/web/src/lib/firebase.ts` с вашими данными
5. Создайте коллекции согласно структуре выше
6. Добавьте тестовые данные (вопросы и варианты ответов)

**Подробная инструкция по настройке Firebase**: см. `firebase-setup.md`

## 💡 Функционал приложения

### 1. Авторизация и регистрация

#### Регистрация:
- Номер телефона (11 цифр)
- Пароль (минимум 6 символов)
- Имя
- Возраст (18-100 лет)
- Пол
- Описание (опционально)

#### Вход:
- Номер телефона
- Пароль
- Кнопка показа пароля

#### Восстановление пароля:
- По номеру телефона и имени
- Установка нового пароля

### 2. Тест на совместимость

- 10 вопросов о ценностях и предпочтениях
- 3 варианта ответа на каждый вопрос
- Прогресс-бар выполнения
- Расчет совместимости с другими пользователями
- Возможность пройти тест заново

### 3. Главная страница (Карточки)

- Просмотр профилей других пользователей
- Фото или градиент-заглушка
- Имя, возраст
- Процент совместимости
- Описание профиля
- Кнопки: ❌ Дизлайк | ❤️ Лайк
- Плавная анимация свайпа

### 4. Система лайков и мэтчей

- Лайк = выражение симпатии
- При взаимном лайке = автоматический мэтч
- Уведомление о новом мэтче
- Невозможность лайкнуть дважды
- Фильтрация просмотренных профилей

### 5. Мэтчи

- Сетка карточек с мэтчами
- Фото/аватарка пользователя
- Имя, возраст
- Процент совместимости
- Кнопка "Написать"
- Кнопка "Удалить мэтч"

### 6. Чаты

- Список всех активных чатов
- Аватарка собеседника
- Имя
- Последнее сообщение
- Время последнего сообщения
- Автообновление каждые 3 секунды

### 7. Детальный чат

- Шапка с аватаркой и именем
- История сообщений
- Разделение своих/чужих сообщений
- Время отправки
- Поле ввода сообщения
- Автоскролл к последнему сообщению

### 8. Профиль

- Аватарка (клик для загрузки фото)
- Имя, возраст, пол, телефон
- Описание профиля
- Статус теста
- Кнопки:
  - Пройти тест (заново)
  - Изменить описание
  - Изменить пароль
  - Выйти
  - Удалить аккаунт

## 📖 Руководство пользователя

### Первый запуск

1. **Регистрация:**
   - Откройте приложение
   - Нажмите "Зарегистрироваться"
   - Введите номер телефона (11 цифр, только цифры)
   - Придумайте пароль (минимум 6 символов)
   - Подтвердите пароль
   - Нажмите "Продолжить"

2. **Заполнение профиля:**
   - Введите имя
   - Укажите возраст (18+)
   - Выберите пол
   - Добавьте описание (опционально)
   - Нажмите "Завершить регистрацию"

3. **Прохождение теста:**
   - При первом входе появится уведомление
   - Нажмите "Пройти тест"
   - Ответьте на 10 вопросов
   - Выберите один из трех вариантов

### Использование приложения

#### Главная страница:
- Смотрите карточки пользователей
- Нажимайте ❤️ если нравится
- Нажимайте ❌ если не подходит
- Карточка уберется с анимацией
- Если закончились новые - нажмите "Показать всех"

#### Мэтчи:
- Открывайте вкладку "Мэтчи"
- Просматривайте взаимные симпатии
- Нажмите "Написать" для начала чата
- Или удалите мэтч

#### Чаты:
- Список всех диалогов
- Выберите чат для открытия
- Пишите сообщения
- Нажмите ← для возврата

#### Профиль:
- Просмотр информации
- Клик по аватарке = загрузка фото
- Редактирование описания
- Смена пароля
- Повторное прохождение теста
- Выход или удаление аккаунта

### Загрузка фото профиля

**Способ 1 - Клик по аватарке:**
- Кликните на круглую аватарку в профиле
- Выберите фото с устройства
- Фото автоматически сохранится

**Способ 2 - Через диалог:**
- Нажмите "Изменить аватарку" (если кнопка есть)
- Выберите файл с устройства
- Или вставьте URL ссылку

**Требования к фото:**
- Форматы: JPG, PNG, WebP
- Максимальный размер: 5MB
- Рекомендуется: квадратное изображение

### Восстановление пароля

1. На странице входа нажмите "Забыли пароль?"
2. Введите номер телефона
3. Введите имя
4. Нажмите "Продолжить"
5. Установите новый пароль
6. Подтвердите пароль
7. Нажмите "Изменить пароль"
8. Войдите с новым паролем

## 🔧 Решение проблем

### Приложение не запускается:

\`\`\`bash
# Удалите node_modules и переустановите
rm -rf node_modules package-lock.json
npm install
npm run dev
\`\`\`

### Ошибка подключения к БД:

1. Проверьте конфигурацию Firebase в `src/lib/firebase.ts`
2. Убедитесь, что проект Firebase активен
3. Проверьте, что Firestore Database включен
4. Проверьте правила безопасности Firestore

### Не загружаются изображения:

- Проверьте размер файла (<5MB)
- Проверьте формат (JPG, PNG, WebP)
- Очистите кеш браузера

### Лайки не работают:

- Откройте консоль браузера (F12)
- Проверьте наличие ошибок
- Убедитесь, что база данных доступна
- Проверьте уникальные ограничения в БД

### Тест выдает ошибку:

- Очистите ответы: `node web/clear-answers.js`
- Проверьте, что в БД есть вопросы
- Перезагрузите страницу

### Не работает авторизация:

- Очистите localStorage браузера
- Проверьте правильность телефона/пароля
- Убедитесь, что пользователь существует
