🎯 ДЕЙСТВИЯ:

1. НАЖАТЬ на сообщение → Открыть меню
2. ВЫБРАТЬ "Ответить" → Включить режим ответа
3. ВВЕСТИ текст → В reply bar появится превью
4. ОТПРАВИТЬ → Ответ связан с исходным
5. НАЖАТЬ [❌] → Отменить режим ответа
