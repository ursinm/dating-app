# 🔧 РЕШЕНИЕ: Очистите localStorage

## ⚠️ Проблема: "Пользователя не найден"

После миграции на email в localStorage остались старые данные с `user_phone`.

---

## ✅ БЫСТРОЕ РЕШЕНИЕ (2 способа):

### Способ 1: Через консоль браузера (F12)

1. Откройте сайт http://localhost:3001
2. Нажмите **F12** → вкладка **Console**
3. Вставьте:
```javascript
localStorage.clear()
location.reload()
```
4. Нажмите Enter
5. ✅ Готово! Перелогиньтесь

---

### Способ 2: Автоматическая очистка (уже добавлено в код)

Код теперь автоматически очищает localStorage если пользователь не найден.

Просто:
1. Откройте http://localhost:3001
2. Вас автоматически перенаправит на `/welcome`
3. Зарегистрируйтесь заново с **email**
4. ✅ Всё работает!

---

## 📝 Почему это произошло?

### Старая схема (user_phone):
```javascript
localStorage: {
  userId: 1,
  userPhone: "79001234567"
}
```

### Новая схема (user_email):
```javascript
localStorage: {
  userId: 1,
  userEmail: "ivan@mail.com"
}
```

После миграции старые userId могут не существовать в новой базе.

---

## 🎯 Что делать дальше:

### 1. Очистите localStorage
```javascript
// В консоли браузера (F12)
localStorage.clear()
```

### 2. Удалите старых пользователей из Firestore
Firebase Console → Firestore → users → Удалите документы с `user_phone`

### 3. Зарегистрируйтесь заново
- Используйте **email** (не телефон!)
- Пример: `test@mail.com`
- Пароль: минимум 6 символов
