### 3. 🗑️ Удаление чатов с удалением матчинга

#### Что добавлено:

##### A. API метод `chatsApi.delete(chatId)`

**Что делает:**
1. Удаляет сам чат
2. Удаляет все сообщения чата
3. Удаляет матчинг между пользователями

```typescript
async delete(chatId: number): Promise<void> {
  // 1. Удаляем чат
  await deleteDoc(chatDoc.ref);
  
  // 2. Удаляем все сообщения
  const messagesQuery = query(messagesCol, where('chat_id', '==', chatId));
  const messagesSnapshot = await getDocs(messagesQuery);
  await Promise.all(messagesSnapshot.docs.map(doc => deleteDoc(doc.ref)));
  
  // 3. Удаляем матчинг (в обе стороны)
  const matchQuery1 = query(
    matchesCol,
    where('match_first_user_id', '==', user1),
    where('match_second_user_id', '==', user2)
  );
  const matchQuery2 = query(
    matchesCol,
    where('match_first_user_id', '==', user2),
    where('match_second_user_id', '==', user1)
  );
  // Удаляем все найденные матчинги
  await Promise.all([...]);
}
```

##### B. UI кнопка удаления в ChatScreen

**Дизайн:**
- Кнопка корзины появляется при наведении на чат
- Красная иконка Trash2
- Подтверждение удаления
- Индикатор загрузки при удалении

**Поведение:**
```
1. Наводим на чат → появляется 🗑️ справа
2. Клик → подтверждение "Удалить чат с {name}? Это также удалит ваш матчинг."
3. Да → удаление (показывается спиннер)
4. Готово → чат исчезает из списка
```

#### Код кнопки:
```tsx
<button
  onClick={(e) => handleDeleteChat(chat.chat_id, e)}
  disabled={deletingChatId === chat.chat_id}
  className="p-2 hover:bg-red-50 rounded-full transition 
             opacity-0 group-hover:opacity-100"
>
  {deletingChatId === chat.chat_id ? (
    <Loader2 className="w-5 h-5 text-red-500 animate-spin" />
  ) : (
    <Trash2 className="w-5 h-5 text-red-500" />
  )}
</button>
```

#### Результат:
- ✅ Можно удалить чат полностью
- ✅ Все сообщения удаляются
- ✅ Матчинг тоже удаляется
- ✅ Пользователи снова могут свайпать друг друга
- ✅ Подтверждение перед удалением
- ✅ Красивая анимация
