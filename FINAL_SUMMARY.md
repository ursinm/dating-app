## 🎯 Что делает этот проект

**Dating App** - современное веб-приложение для знакомств с системой подбора по совместимости.

### Основной функционал:
- ✅ Регистрация и авторизация через Firebase
- ✅ Тест на совместимость (10 вопросов)
- ✅ Умный подбор партнеров на основе совместимости
- ✅ Система лайков и мэтчей в реальном времени
- ✅ Чаты с поддержкой медиафайлов
- ✅ Профили пользователей с фото
- ✅ Адаптивный дизайн для всех устройств

### Технологии:
- **Frontend:** React 18, TypeScript, Vite, Tailwind CSS
- **Backend:** Firebase (Firestore, Authentication, Storage)
- **UI:** Framer Motion для анимаций

## 🚀 Как загрузить на GitHub

У вас есть 3 варианта:

### Вариант 1: Через терминал с Personal Access Token

1. Создайте токен на https://github.com/settings/tokens
2. Выполните:
   ```bash
   cd /Users/amal/Downloads/dating-main
   git push origin main
   ```
3. Используйте токен как пароль

### Вариант 2: Через GitHub Desktop

1. Скачайте [GitHub Desktop](https://desktop.github.com/)
2. Откройте папку проекта
3. Нажмите "Publish repository"

### Вариант 3: Через веб-интерфейс

1. Откройте https://github.com/ursinm/dating-xx
2. Нажмите "Upload files"
3. Перетащите файлы проекта
