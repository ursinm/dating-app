## ⚙️ Как работает:

### 1. При входе пользователя:
```
App.tsx → useEffect → startOnlineStatusUpdater(userId)
  ↓
1. Устанавливается is_online: true
2. Обновляется last_seen
3. Запускается интервал обновления каждые 30 сек
4. Добавляется обработчик beforeunload
```

### 2. Во время активности:
```
Каждые 30 секунд:
  updateLastSeen(userId) → Firestore updates last_seen
```

### 3. При выходе/закрытии:
```
beforeunload event / useEffect cleanup
  ↓
setUserOffline(userId)
  ↓
is_online: false, last_seen: current timestamp
```

## 🕒 Форматирование времени:

### formatLastSeen() возвращает:
```
< 1 мин   → "только что"
< 60 мин  → "5 мин назад"
< 24 ч    → "3 ч назад"
1 день    → "вчера"
< 7 дней  → "3 дн назад"
> 7 дней  → "20 янв"
```

## 🔧 Техническая реализация:

### Автообновление:
```typescript
// Запуск
const stopUpdater = startOnlineStatusUpdater(userId);

// Интервал
setInterval(() => {
  updateLastSeen(userId);
}, 30000); // 30 сек

// Остановка
stopUpdater(); // cleanup
```

### Обработка закрытия:
```typescript
window.addEventListener('beforeunload', () => {
  setUserOffline(userId);
});
```
